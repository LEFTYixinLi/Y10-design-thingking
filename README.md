# 🌍 打破信息孤岛：国际课程学生交流合作项目

> 一个旨在连接 IB / A-Level / AP 等国际课程学生，打破校际信息壁垒、促进跨校合作与交流的探索性项目。

## 📖 项目简介

在当前国际课程生态中，不同学校、不同课程体系的学生之间，信息共享渠道往往相对有限。宝贵的经验、活动和竞赛资源通常只在小范围或熟人网络中流转，导致许多学生面临“信息差”和“找不到队友”的困境。

本项目致力于探索并搭建一种更适合国际课程学生的交流方式。我们关注的不仅仅是学术，更聚焦于**课程之外**的广阔天地：
*   **课外项目合作**：跨校组队参与竞赛、科研或兴趣探索。
*   **志愿活动**：共享公益资源，联合组织志愿服务。
*   **社团交流**：同类社团间的经验分享与联合活动。
*   **跨校运动竞技**：打破校际壁垒，寻找切磋舞台。

目前，项目正处于**前期调研与方向探索阶段**。我们通过深度访谈与问卷调研，收集真实痛点，以决定最终的产品形态（社群、信息库、还是小程序平台）。

## 🔍 核心调研发现 (基于问卷与访谈)

1.  **学业压力是焦虑的绝对主导源**：课程难度、标化考试、英语学习位列前三。
2.  **信息类支持是最高杠杆的干预方向**：高达 74.42% 的学生最期待“AP课程介绍与知识库”（选课红黑榜、复习资料等）。
3.  **交流壁垒本质是“平台缺失”而非“意愿缺失”**：超半数学生认为“我不认识他们”是最大壁垒，其次是“缺乏交流平台”。
4.  **学生期待轻量化的支持**：如“报名统计”与“评论沟通”功能，或微信群+帖子式的形式。
